# AI 工作台实现对照 v2

| 对照项 | 门户 Codex 基线 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| 背景 | 7rem 网格、蓝/青环境光 | 同样的网格节奏与环境光 | 一致 |
| 顶部 | 工作台标题、恢复连接、能力状态、返回门户 | 改名 AI 工作台，其余骨架保留 | 一致 |
| 主容器 | 单一圆角玻璃 stage | 单一 24px 圆角玻璃 stage | 一致 |
| 左栏 | 项目与会话层级 | 保留 Project A、搜索、新建和会话列表 | 一致 |
| 对话区 | 标题栏、消息流、底部玻璃输入器 | 保留相同容器模型与层级 | 一致 |
| 执行轨迹 | 随助手消息展开 | 运行、停止、授权失效均进入消息流 | 一致 |
| 响应式 | 窄屏保留对话主区 | Chrome 390 × 844 下 `scrollWidth=innerWidth=390` | 通过 |
| 模型 | 运行时目录 | 本地 CLIProxyAPI 动态显示 16 个模型 | 通过 |

首屏文案对照：没有引入营销标题、指标卡或独立右侧轨迹栏。门户骨架上只增加了隔离模式、CLIProxyAPI 模型数和授权状态这些必要信息。
