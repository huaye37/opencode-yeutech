# AI 工作台实现对照 v3

| 对照项 | 门户 Codex 基线 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| 背景 | 7rem 网格、蓝/青环境光 | 同样的网格节奏与环境光 | 一致 |
| 顶部 | 工作台标题、恢复连接、能力状态、返回门户 | 改名 AI 工作台，其余骨架保留 | 一致 |
| 主容器 | 单一圆角玻璃 stage | 单一 24px 圆角玻璃 stage | 一致 |
| 左栏 | 真实项目与会话层级 | 显示快照中 7 个真实项目；未归属数据合并到“独立会话” | 一致，无虚构项目 |
| 对话区 | 标题栏、消息流、底部玻璃输入器 | 保留相同容器模型与层级 | 一致 |
| 执行轨迹 | 随助手消息展开 | 运行、停止、授权失效均进入消息流 | 一致 |
| 历史接续 | 原会话原位继续 | 首次发送静默映射 OpenCode，保留原 ID，seed 不显示 | 已实现 |
| 去重 | 一个会话一个条目 | 已映射 OpenCode session 不再出现于独立会话 | 已实现 |
| 状态隔离 | 切换会话不携带上一会话状态 | 选择时清空并按 runtime session 重读 | 已实现 |
| 响应式 | 窄屏保留对话主区 | Chrome 390 × 844 下 `scrollWidth=innerWidth=390`；抽屉可打开且选择后自动关闭 | 通过 |
| 模型 | 运行时目录 | 本地 CLIProxyAPI 动态显示 16 个模型 | 通过 |

本地增强项为会话搜索、Markdown 导出、移动端项目抽屉和专注模式。它们不改变原有的项目—会话—消息主流程。附件和项目文件仍禁用，等本地文件接口真正接入后再验收。
